Voting app functionality

1. user sign in / sign up.
2. see the list of candidate in a election.
3. vote one of the candidate, after voting, user can't vote again in the same election.
4. there is a route which shows the list of candidates in the election and their live vote counts sorted by their vote count.
5. user data must contain their one unique government id proof named : aadhar card number.
6. there should be one admin who can only maintain the table of candidates for the elections and the admin can't vote.
7. user can change their password.
8. user can only login with adhar card number and password.
9. users verification get's expired after a period of time.
10.user can send reverification request to get verified again.
11.admin can approve the reverification and can also permanently block the fake or expired user.
12.admin can activate/deactivate voters.
13.amin can create election and can set their start and end date.
----------------------------------------------------------------

Routes

User Authentication:
    /signup: POST - Create a new user account.
    /login: POST - Log in to an existing account. [ aadhar card number + password ]

Voting: 
    /Candidates: GET - Get the list of candidates.
    /Vote/:candidateID: POST - Vote for a specific candidate.

Vote Counts:
    /vote/counts: GET - get the list of candidates sorted by their vote counts.

User Profile:
    /profile: GET - Get the user's profile information.
    /profile/password: PUT - Change the user's password.


Admin Candidate Managemet:
    /candidates: POST - Create a new candidate.
    /candidates/:candidateID: PUT - Update an existing cndidate.
    /candidates/:candidateID: DELETE - Delete a candidate from the list.

Admin voters Management:
    /user/deactivate/:userId: PUT - admin deactivates invalid/expired voters
